GROME: Additional Results

This is a self-contained copy of the supplementary webpage.
It includes all videos, poster images, and comparison frames used by the page.

To view locally (Python 3, no additional packages required):

    python3 serve.py

Then open http://127.0.0.1:8000/ in a browser.
If port 8000 is occupied, use python3 serve.py --port 8080 instead.

Use the local server rather than opening index.html directly.
The included server supports video seeking through HTTP byte ranges.
Keep the assets folder and the other files together when copying the page.
The page can also be served by a static web server with HTTP byte-range support.
